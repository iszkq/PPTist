# PPTist 中文说明

请先阅读项目根目录的 [README.md](README.md)。其中包含完整的安装、启动、PPTX 导入、HTML 动效、网页嵌入和工程文件说明。

本项目适合以下场景：

- 用 PPTist 编辑和放映普通演示文稿。
- 在 PPT 页面中叠加透明 HTML/CSS/JavaScript 动效。
- 使用粒子照片秀制作雨、雪、樱花、星星、枫叶和萤火虫效果。
- 将允许 iframe 的外部网页嵌入演示页面。
- 使用 `.pptist` 工程文件在不同电脑之间共享完整工程。

最短启动命令：

```bash
git clone https://github.com/iszkq/PPTist.git
cd PPTist
pnpm install
pnpm dev
```

浏览器访问 <http://127.0.0.1:5173>。
